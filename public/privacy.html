Privacy & data

Orbit is a job-search and outreach assistant. This notice describes the software's behavior. The service operator must publish their identity and contact details before a broad public launch.

Your workspace

Account credentials, application materials, job history, prompts and outreach replies are stored in your separate account workspace. Passwords are salted and hashed. API keys and Gmail tokens are encrypted using the server's vault key. The service operator can access application data and is responsible for access controls, backups and deletion requests.

Connected services

In local AI mode, relevant CV/resume, prompt and reply context is processed on the service owner’s computer using Ollama. The private worker receives tasks over authenticated HTTPS and keeps inference inputs in memory. In optional OpenAI mode, this context is sent to your configured OpenAI project. Gmail access is used to create drafts, send approved messages, and read tracked outreach threads. Provider policies and retention rules also apply. Local discovery reads the public Arbeitnow job feed without sending applicant details to it. Optional OpenAI mode can incur API charges.

Your controls

You can pause daily discovery, disconnect Gmail, and export your workspace in Settings. Email sending requires approval of the exact draft. Orbit does not infer rejection from silence or guarantee hiring success. Contact the service operator for account removal; self-service account deletion and password recovery are not implemented in this version.

Google user data

Gmail data is used only for the user-directed job outreach and reply analysis features described above. It is not sold or used for advertising. Broad distribution depends on completing Google's applicable OAuth verification requirements.
